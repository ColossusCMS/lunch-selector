# 🍱 오늘 점심 뭐 먹지?

Google Sheets에 적어둔 가게 목록에서, 오늘 정기휴무인 곳을 빼고 1·2·3순위를 룰렛으로 뽑아주는 정적 사이트입니다. 서버 없이 HTML/CSS/JS만으로 동작해서 GitHub Pages에 그대로 올릴 수 있어요.

## 사용법

1. 점심 그룹을 고릅니다. (마지막에 고른 그룹은 브라우저가 기억해요.)
2. 필요하면 업종 버튼을 켭니다. 여러 개를 켜면 하나라도 해당하는 가게가 후보예요.
3. **🎰 돌리기**를 누르면 1순위가 뽑히고, 2·3순위가 차례로 나타납니다.
4. 1순위가 내키지 않거나 임시 휴무라면 2순위, 3순위로 가면 돼요.

## 가게 목록 시트

### 만들기

- 탭 이름: `가게목록`
- **헤더 첫 셀은 반드시 `A1`**이고, 1행에 한 줄로 적습니다. 데이터는 2행부터.
- 열 순서는 자유. 아래에 없는 열(예: 전화번호)은 무시됩니다.
- 셀 병합, 2줄 헤더는 쓰지 마세요.

| 열 | 필수 | 적는 법 | 예 |
|---|---|---|---|
| `가게명` | 필수 | 비어 있으면 그 행은 건너뜀 | 김밥천국 |
| `업종` | | 쉼표로 여러 개 | `분식,한식` |
| `그룹` | 필수 | 쉼표로 여러 개. 비어 있으면 어디에도 안 나옴 | `1팀,2팀` |
| `정기휴무` | | 요일 한 글자를 쉼표로 (`월요일`도 인식) | `토,일` |
| `사용여부` | | 체크박스 (삽입 → 체크박스). 해제하면 후보에서 빠짐 | ☑ |
| `메모` | | 결과 카드에 작게 표시 | 짬뽕 맛집 |

예시는 [`data/sample-stores.csv`](data/sample-stores.csv)를 참고하세요.

### 공유

시트의 **공유 → 일반 액세스: 링크가 있는 모든 사용자 / 편집자**. 사이트의 "✏️ 가게 목록 편집하기" 링크로 누구나 시트를 고칠 수 있어요. 실수로 지웠다면 **파일 → 버전 기록**으로 되돌리면 됩니다.

### 연결

[`js/config.js`](js/config.js)에서:

```js
export const SHEET_ID = '...';      // 시트 주소의 /d/ 와 /edit 사이 값
export const SHEET_TAB = '가게목록'; // 탭 이름을 바꿨다면 여기도
```

시트를 고치면 새로고침만 하면 반영됩니다.

### 대안: 웹에 게시

시트 ID를 드러내고 싶지 않으면 **파일 → 공유 → 웹에 게시**에서 `가게목록` 탭을 **CSV**로 게시하고, 나온 주소를 `CSV_URL_OVERRIDE`에 넣으세요. 이 방식은 반영까지 최대 5분 정도 걸릴 수 있어요. (편집 링크는 `SHEET_ID`가 있을 때만 보입니다.)

## 로컬 실행

`index.html`을 더블클릭하면 브라우저 보안 정책 때문에 동작하지 않아요. 간단한 서버로 띄우세요.

```bash
npx serve .
```

시트 대신 예시 데이터로 보고 싶다면 `CSV_URL_OVERRIDE = 'data/sample-stores.csv'`.

## 테스트

```bash
npm test
```

Node 22 이상. 외부 의존성은 없습니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 지정하면 1~2분 뒤 `https://<계정>.github.io/<저장소>/`에서 열립니다.
