# 설치·운영 가이드

직접 띄우거나 시트를 연결할 때 보는 문서입니다. 프로젝트 소개는 [README](../README.md)에 있어요.

## 사용법

0. 맨 위 **[🍱 점심] [☕ 카페]**로 고를 목록을 바꿉니다. (탭이 하나뿐이면 이 버튼은 숨겨져요.)
1. 그룹 버튼을 하나 고릅니다. **[전체]**를 고르면 그룹 구분 없이 모든 가게가 후보예요. (마지막에 고른 그룹은 브라우저가 기억해요.)
2. 필요하면 업종 버튼을 켭니다. 여러 개를 켜면 하나라도 해당하는 가게가 후보이고, **[전체]**를 누르면 업종 선택이 모두 풀려요.
3. **🎰 돌리기**를 누르면 1순위가 뽑히고, 2·3순위가 차례로 나타납니다. 주소가 적힌 가게는 아래 지도에 순위 핀으로 표시돼요.
4. 1순위가 내키지 않거나 임시 휴무라면 2순위, 3순위로 가면 돼요.

## 가게 목록 시트

### 만들기

- 탭 이름: `가게목록`
- **헤더 첫 셀은 반드시 `A1`**이고, 1행에 한 줄로 적습니다. 데이터는 2행부터.
- 열 순서는 자유. 아래에 없는 열(예: 전화번호)은 무시됩니다.
- 셀 병합, 2줄 헤더는 쓰지 마세요.

| 열 | 필수 | 적는 법 | 예 |
|---|---|---|---|
| `가게명` | 필수 | 비어 있으면 그 행은 건너뜀 | 김밥천국 |
| `업종` | | 쉼표로 여러 개 | `분식,한식` |
| `그룹` | 필수 | 쉼표로 여러 개. 비어 있으면 어디에도 안 나옴 | `1팀,2팀` |
| `정기휴무` | | 요일 한 글자를 쉼표로 (`월요일`도 인식) | `토,일` |
| `사용여부` | | 체크박스 (삽입 → 체크박스). 해제하면 후보에서 빠짐 | ☑ |
| `메모` | | 결과 카드에 작게 표시 | 짬뽕 맛집 |
| `주소` | | 도로명·지번 주소. 지도 핀과 "📍 카카오맵" 링크에 쓰임. 비우면 지도에서만 빠짐 | 서울 중구 세종대로 110 |

예시는 [`data/sample-stores.csv`](../data/sample-stores.csv)를 참고하세요.

### 공유

시트의 **공유 → 일반 액세스: 링크가 있는 모든 사용자 / 편집자**. 사이트의 "✏️ 가게 목록 편집하기" 링크로 누구나 시트를 고칠 수 있어요. 실수로 지웠다면 **파일 → 버전 기록**으로 되돌리면 됩니다.

### 연결

[`js/config.js`](../js/config.js)에서:

```js
export const SHEET_ID = '...';     // 시트 주소의 /d/ 와 /edit 사이 값 (편집 링크용)
export const PUBLISH_URL = '...';  // "웹에 게시" 주소에서 /pub 까지. 비우면 SHEET_ID로 gviz 방식
export const MODES = [             // 상단 전환 버튼 = 시트 탭
  { id: 'lunch', label: '🍱 점심', heading: '🍱 오늘 점심 뭐 먹지?', tab: '점심메뉴', gid: '0' },
  { id: 'cafe',  label: '☕ 카페', heading: '☕ 오늘 카페 어디 가지?', tab: '다과(커피)메뉴', gid: '611891333' },
];
```

- 탭마다 열 구성은 같습니다. 탭을 하나 더 쓰려면 `MODES`에 한 줄 추가하세요.
- `gid`는 그 탭을 열었을 때 주소창 끝 `#gid=` 숫자, `tab`은 탭 이름입니다. 게시 방식은 `gid`, gviz 방식은 `tab`을 쓰고, 그 값이 빈 모드는 버튼에서 빠집니다.
- 시트를 고치면 새로고침만 하면 반영됩니다.

### 지도 (카카오맵)

[`js/config.js`](../js/config.js)의 `KAKAO_MAP_KEY`에 카카오 **JavaScript 키**를 넣으면 켜지고, 비우면 꺼집니다.

1. [카카오디벨로퍼스](https://developers.kakao.com)에서 앱을 만들고 **[카카오맵] → 사용 설정 ON**.
2. **[앱] → [플랫폼 키] → [JavaScript 키] → [JavaScript SDK 도메인]**에 사이트 주소를 등록 (경로 없이 도메인까지만).
   - 배포: `https://<계정>.github.io`
   - 로컬: `http://localhost:5173` (등록한 포트로 띄워야 지도가 떠요: `npx serve -l 5173 .`)
3. 같은 화면의 JavaScript 키를 `KAKAO_MAP_KEY`에 넣습니다. 등록한 도메인에서만 동작하므로 공개돼도 괜찮아요.

주소를 못 찾거나 지도를 불러오지 못하면 지도만 숨고 추천은 그대로 동작합니다.

### 대안: 웹에 게시

시트를 공개 공유하고 싶지 않으면 **파일 → 공유 → 웹에 게시**에서 **전체 문서**를 **CSV**로 게시하고, 나온 주소의 `/pub` 까지를 `PUBLISH_URL`에 넣으세요. 이 방식은 반영까지 최대 5분 정도 걸릴 수 있어요. (편집 링크는 `SHEET_ID`가 있을 때만 보입니다.)

## 로컬 실행

`index.html`을 더블클릭하면 브라우저 보안 정책 때문에 동작하지 않아요. 간단한 서버로 띄우세요.

```bash
npx serve .
```

시트 대신 예시 데이터로 보고 싶다면 `PUBLISH_URL`과 `SHEET_ID`를 비우세요.
