# 공지 작성 가이드

## 공지관리 탭에서 작성해요

공지마다 새 `ID`를 만들고 `사용`을 체크해요. `시작일`과 `종료일`에는 한국 날짜를 적어요. 종료일을 비우면 계속 표시돼요. `제목`과 `내용`은 필수예요. 팝업 하단에 버튼 하나를 넣으려면 `링크`에 HTTPS 주소를 넣고 `버튼`에 글씨를 적어요. 버튼 글씨를 비우면 ‘자세히 보기’가 표시돼요. [설치·운영 가이드의 공지 팝업 절](SETUP.md#공지-팝업)

아래 문법은 `내용` 칸에서 사용해요. 셀 안의 줄바꿈은 화면에 반영되고, 빈 줄은 문단을 나눠요. 하이픈 앞에 공백을 둔 `  - 항목`도 목록으로 인식해요.

| 종류    | 쓰는 법                                              | 화면에 보이는 내용                                                             |
| ----- | ------------------------------------------------- | ---------------------------------------------------------------------- |
| 굵게    | `{굵게:중요}`                                         | **중요**                                                                 |
| 기울임   | `{기울임:기울여 보임}`                                    | 글자가 이탤릭체로 보여요.                                                         |
| 글자크기  | `{크게:글자 크게}, {작게:글자 작게}`                          | 지정 크기로 글자가 표시돼요.                                                       |
| 색 글자  | `{빨강:마감}`, `{파랑:안내}`, `{초록:가능}`, `{주황:참고}`        | 지정한 색으로 표시해요.                                                          |
| 본문 링크 | `{링크:안내 문서\|https://example.com/guide}`           | ‘안내 문서’를 누르면 새 탭에서 열려요. 본문에 여러 개 넣을 수 있어요.                             |
| 목록    | 줄 맨 앞에 `- 항목`                                     | 이어지는 항목을 점 목록으로 묶어요.                                                   |
| 이미지   | 줄 전체에 `{이미지:https://images.example.com/poster.png\|베타 안내\|60%}` | 저장소 파일 이름이나 https 이미지 주소를 쓸 수 있어요. 팝업 가운데에 폭 60%로 표시되고 ‘베타 안내’가 대체 텍스트가 돼요. |

굵게와 색은 섞어 쓸 수 있어요. `{굵게:{빨강:오늘 마감}}`처럼 쓰면 굵은 빨강 글씨가 돼요. 최대 네 단계까지 감쌀 수 있어요. 링크 글씨와 이미지 설명은 입력한 그대로 표시돼요. 링크 글씨에는 구분 기호인 `|`를 쓸 수 없어요. 모르는 종류 이름은 글자 그대로 보여요. 짝이 맞는 문법의 해석에 실패하면 여는 괄호부터 닫는 괄호까지 통째로 글자로 보여요. 예를 들어 `{링크:{굵게:안내}|http://example.com}`은 주소가 HTTPS가 아니어서 안쪽 굵게 문법까지 글자 그대로 보여요.

아래 예시를 `내용` 셀 하나에 넣을 수 있어요.

```text
{이미지:beta-poster.png|베타 안내}
이번 주 {굵게:AI 추천 베타}를 시작해요.
{빨강:12/5까지} 의견을 남겨 주세요.
- 비 오는 날엔 국물 위주로 추천해요
자세한 내용은 {링크:안내 문서|https://example.com/guide}에서 확인해 주세요.
```

## 이미지를 넣어요

`내용`에서 이미지마다 `{이미지:대상|설명|크기}`를 한 줄로 써요. 공지당 최대 세 장을 넣을 수 있고, 이미지 한 장만 적어도 공지가 돼요.

```text
{이미지:beta-poster.png}
{이미지:beta-poster.png||40%}
{이미지:https://images.example.com/shared/preview?key=공유키&size=preview|베타 안내|60%}
```

- 대상에는 저장소 파일 이름이나 2,000자 이하의 HTTPS 이미지 주소를 적어요. 주소는 확장자가 없어도 돼요.
- 설명을 비우면 공지 제목이 대체 텍스트가 돼요. 설명에는 구분 기호 `|`를 쓸 수 없어요. 주소에 `|`가 필요하면 `%7C`로 써요.
- 크기는 `10%`에서 `100%`까지 정수로 써요. 생략하거나 비우면 100%이고, 100%보다 작으면 가운데에 놓여요.

### 저장소 파일을 쓸 때

1. 이미지 파일을 저장소의 `images/notice/`에 넣어요. 확장자 앞 이름은 영문·숫자·하이픈·밑줄 1~60자로 작성해요. 확장자는 `png`, `jpg`, `jpeg`, `webp`, `gif`를 쓸 수 있어요.
2. 이미지 파일을 푸시하고 GitHub Pages에서 해당 파일이 열리는지 확인해요.
3. 시트의 `내용`에 경로를 뺀 파일 이름으로 이미지 줄을 적어요.

이미지를 교체할 때는 새 파일 이름을 써요. 브라우저와 GitHub Pages가 예전 이름의 파일을 캐시할 수 있어요.

### 외부 이미지 주소를 쓸 때

- Immich 주소는 예시처럼 HTTPS 이미지 경로와 공유 키를 넣는 형태예요. 버전에 따라 경로가 다르니, 붙여 넣기 전에 시크릿 창에서 로그인 없이 이미지만 뜨는지 확인해요. 큰 원본은 `size=preview` 같은 웹용 크기로 불러오는 편이 좋아요.
- 공지 시트는 공개돼요. 주소의 공유 키도 공개되므로 그 키로 공유한 사진·앨범을 누구나 볼 수 있어요. 공지 전용 앨범 또는 사진 한 장의 공유 링크만 써요.
- 시트에서 주소를 바꾸면 저장소에 새 파일을 올리는 과정 없이 교체할 수 있어요. 이미지 서버가 꺼지거나 링크가 만료되면 해당 이미지만 팝업에서 빠져요.

## 문법 종류를 추가해요

1. [공지 문법 파서](../js/notice-markup.js)의 `KINDS`에 종류 이름과 고정 태그·클래스 대응을 한 줄 추가해요.
2. [스타일시트](../css/style.css)에 클래스를 추가해요. 새 글자 색이 필요하면 라이트·다크 토큰을 각각 지정하고 팝업 배경과 4.5:1 이상 대비되는지 확인해요.
3. [공지 문법 테스트](../tests/notice-markup.test.js)에 새 종류의 파싱과 렌더링에 쓰일 클래스를 검사하는 테스트를 추가해요. `npm test`와 `npm run bump`를 실행해요. 문법은 브라우저(`js/notice-markup.js`)에서 해석하므로 추천 서버는 고칠 필요가 없어요.
