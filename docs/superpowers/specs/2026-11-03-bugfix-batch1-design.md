## 범위

| ID | 문제 | 고친 뒤 동작 |
|---|---|---|
| B1 | `사용여부`에 `아니요`·`no`·`x`·`미사용`·`off`를 적어도 사용으로 처리됨 (`js/stores.js:6`) | 위 값들도 "미사용"으로 인식. 기존 값(`false`·`n`·`아니오`·`0`)과 대소문자·앞뒤 공백 무시, 빈 칸 = 사용은 그대로 |
| B2 | 시트 요청에 제한 시간이 없어 응답이 멈추면 "불러오는 중..."에 갇히고 다시 시도 버튼도 안 나옴 (`js/data.js`) | 요청부터 본문 읽기까지 **10초** 안에 끝나지 않으면 실패. 화면은 기존 실패와 같음("가게 목록을 불러오지 못했어요" + 다시 시도) |

| B4 | 사용 가능한 모드가 0개(설정 실수)면 `selectMode(undefined)`에서 앱 전체가 죽음 (`js/app.js` 마지막 줄) | "설정된 메뉴가 없어요" 안내, 돌리기 비활성 |
| B6′ | `cachedLookup` 주석이 "실패는 캐시하지 않는다"인데 실제로는 못 찾은 결과(`null`)를 캐시함 (`js/map.js:21`) | **동작은 그대로**, 주석만 실제에 맞게: "예외는 캐시하지 않고 다시 묻는다. 못 찾은 결과(null)는 캐시한다." |
