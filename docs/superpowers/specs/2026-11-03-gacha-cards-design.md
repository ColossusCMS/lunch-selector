# 가챠 카드 — 설계

- 날짜: 2026-11-03
- 계획: `docs/superpowers/plans/2026-11-03-gacha-cards.md`
- 디자인 시안(사용자 승인): `docs/superpowers/specs/assets/2026-11-03-gacha-cards-mockup.html` — 브라우저로 열어 본다
- 선행: `2026-11-03-rating-design.md`(별점·좋아요), `2026-11-03-rating-modal.md`

## 왜

지금 결과는 1순위가 이름만 크게 나오고, 2·3순위는 단순한 카드다. 별점·좋아요가 생긴 김에 결과를 **가챠 게임의 수집 카드처럼** 보여주고 싶다. 1순위는 1순위답게 화려해야 한다. 2·3순위도 지금보다 카드다워야 한다. 특정 게임을 따라 하지 않고 장르의 일반 문법(등급, 빛, 뒤집기)만 빌린다.

## 핵심 구조 (사용자 결정)

**순위는 '무대', 평점은 '등급'.** 두 축을 섞어 두 가지 재미를 다 잡는다.

| 축 | 무엇을 정하나 |
|---|---|
| 순위(1·2·3) | 카드 크기(1순위 큼), 등장 순서, 1순위 뒤집기 연출, **메달 뱃지**(🥇🥈🥉, 카드 오른쪽 위 모서리), **카드 외곽에 번지는 빛**(금·은·동, 블러 글로우) |
| 평점 등급 | 카드 테두리·바탕·무늬·움직임, 왼쪽 위 등급 이름표 |

카드 몸통 색을 금·은·동으로 칠하지 않는다. 금·은·동은 외곽 빛과 메달로만 표현한다.

## 등급 (사용자 결정: 보석)

평균 별점으로만 나눈다. 좋아요는 누적 숫자라 기준으로 쓰지 않고 표시만 한다.

| 등급 | 이름표 | 조건 |
|---|---|---|
| 미확인 | `❔ 미확인` | 별점이 있는 평가 **2건 미만** |
| 원석 | `🪨 원석` | 평균 3.0 미만 |
| 에메랄드 | `💚 에메랄드` | 3.0 이상 4.0 미만 |
| 루비 | `❤️ 루비` | 4.0 이상 4.5 미만 |
| 다이아 | `💎 다이아` | 4.5 이상 |

- 평균은 화면 표시와 같은 **소수 첫째 자리 반올림 값**으로 비교한다(화면 `★4.5`인데 루비로 나오는 일이 없게).
- 최소 건수(2)와 경계(3.0·4.0·4.5)는 한 곳의 상수로 둔다. 운영하며 조정할 수 있다.
- 집계 단위는 기존과 같다(모드 + 가게명).

## 카드 디자인 (사용자 승인: 시안 그대로)

시안의 표현을 기준으로 한다. 크기·간격·실제 화면과의 조화는 구현자가 다듬는다.

- **두 형태**: 1순위 큰 카드, 2·3순위 작은 카드(두 장 나란히). 배치는 지금처럼 1순위가 위, 2·3순위가 아래다.
- **카드 내용**: 등급 이름표(왼쪽 위), 메달(오른쪽 위 모서리), 가게명, 업종·메모(기존 `describe`), 평가 줄, `📍 카카오맵` 링크.
- **평가 줄**:
  - 원석 이상: `★4.2 · 👍12` (좋아요 0이면 `★4.2`)
  - 미확인: 평균은 보이지 않는다(1건 평균은 오해를 부른다). 좋아요가 있으면 `👍3 · 평가 부족`, 없으면 `아직 평가가 부족해요`(작은 카드는 `평가 부족`).
- **등급별 표현** (낮을수록 단순, 높을수록 화려):
  - 미확인: 줄무늬 테두리, 어두운 바탕, 큰 `?` 워터마크
  - 원석: 회색 돌 테두리, 장식 없음
  - 에메랄드: 초록 보석 테두리, 모서리 결정 무늬
  - 루비: 진한 빨강 이중 테두리, 깜빡이는 반짝임
  - 다이아: 무지개 테두리가 천천히 돌고, 빛줄기가 카드를 훑고 지나감, 반짝임 여러 개
- 라이트·다크 둘 다(시안에 다크 예시 있음).
- 기존 별도 배지(`.rating-badge`, `#reel-rating`)는 없앤다. 그 정보는 카드의 평가 줄로 옮긴다.

> **변경(2026-11-03, 사용자 실물 확인 후):** 뒷면은 B가 아니라 **시안 C(메뉴판·식기)**로 바꾼다(B는 실물에서 타로카드 느낌이라 어울리지 않음). 연출 순서는 **회전 끝 → 뒷면 `?` → 2순위 → 3순위 → 1순위 뒤집기**(약 3.2초)로 바꾼다(2·3순위가 회전 도중 나오지 않게). 상세는 `docs/agents/handoffs/004-gacha-cards.md` "PM 추가 지시 2차". 아래 B·"그동안" 서술보다 이 메모가 우선한다.

## 1순위 카드 뒷면 (사용자 결정: 시안 B "밤하늘·별" → C로 변경)

- 시안: `docs/superpowers/specs/assets/2026-11-03-gacha-card-back-mockup.html`의 **B**.
- **처음부터** 1순위 자리에 1순위 큰 카드와 같은 크기의 뒷면이 놓여 있다. 첫 화면, 모드·그룹·업종 변경 뒤(`resetResult`)에도 뒷면 상태로 돌아간다. 지금의 `?` 릴 박스를 대체한다. 크기가 처음부터 같아 돌릴 때 화면이 출렁이지 않는다.
- 대기 중 뒷면: 남보라 밤하늘 바탕, 위·아래 작은 별 무늬, 가운데 금빛 `?`(은은한 광채), 그 아래 `돌려서 오늘의 카드를 확인하세요`.
- 돌리는 중: 같은 뒷면 위에서 가게 이름이 빠르게 바뀐다(`?`·안내 문구 대신).
- 라이트·다크 모두 같은 밤하늘 뒷면(다크에서 테두리 대비만 조정).

## 연출 순서 (사용자 결정)

1. `돌리기`를 누르면 1순위 자리의 **카드 뒷면**(위 시안 B) 위에서 이름이 돌기 시작한다. 뒷면 위에서 지금처럼 **가게 이름이 빠르게 돈다**(기존 릴의 재미 유지).
2. 그동안 아래에서 **2순위 → 3순위** 카드가 차례로 나타난다. 2·3순위는 뒤집기 없이 지금처럼 나타난다(페이드·올라오기 등 구현자 재량).
3. 마지막으로 1순위 카드가 **뒤집히며** 앞면이 드러난다.
   - 다이아: 뒤집히는 순간 **빛이 터진다**(밝은 섬광/광채). 기존 폭죽도 함께.
   - 미확인: 앞면에 큰 `?` 실루엣이 덮여 있다가 **벗겨지듯 사라지며** 가게가 드러난다. 기존 폭죽도 함께.
   - 그 밖의 등급: 뒤집기 + 기존 폭죽.
4. 이후 지도 표시 등 기존 흐름은 그대로다.

전체 길이는 지금과 비슷하게(릴 약 2초 + 공개) 유지한다. 오래 기다리게 하지 않는다.

**동작 줄이기(`prefers-reduced-motion`)**: 회전·뒤집기·빛줄기·반짝임·섬광을 끄고, 지금의 `calm` 경로처럼 결과 카드를 바로 보여준다. 등급 색과 테두리는 그대로 보인다.

## 평점을 쓸 수 없을 때

다음 경우에는 **등급 없는 기본 카드**를 쓴다. 메달·외곽 빛·뒤집기 연출은 있고, 등급 이름표·평가 줄·등급 장식은 없다. 바탕은 원석보다도 담백하게, 기존 톤으로 한다.
- 평점 설정(`RATING`)이 비어 기능이 꺼짐
- 평점 CSV를 아직 받지 못했거나 실패함

평점 CSV를 받았는데 그 가게 기록이 없으면 **미확인**이다.

## 접근성

- 화면 낭독기 안내(`#announce`)에 등급을 붙인다: `1순위 본죽(다이아), 2순위 김밥천국(미확인), …`. 미확인도 등급으로 읽는다. 등급 없는 기본 카드면 지금처럼 이름만.
- 장식 요소(반짝임, 빛줄기, 워터마크)는 `aria-hidden`.
- 등급 이름표와 평가 줄은 텍스트라 그대로 읽힌다.
- 뒤집히기 전 1순위 앞면 내용이 미리 읽히지 않게 한다(2·3순위도 공개 전에는 숨김).

## 비목표

- 카드 "뽑기" 연출 고도화(카드팩 열기, 여러 장 펼치기 등) — 다음 작업
- 가게 사진·아이콘
- 좋아요 기반 등급, 등급별 확률 조정(뽑기 확률은 지금 그대로 균등)
- 평가 모달·평점 기록 방식 변경

## 제약

- 의존성 0, CSS·JS만. 이미지 파일 추가 없이 CSS 그라데이션·그림자·애니메이션으로 만든다.
- 등급 판정은 순수 함수로 테스트한다. `textContent`만 쓴다.
- 기존 테스트는 유지하되, 바뀌는 API의 테스트는 교체한다. 집계 결과에 건수 필드가 추가되므로 해당 기대값은 갱신한다. `formatBadge`는 카드 평가 줄용 함수로 대체하고 그 테스트도 교체한다(테스트 총수는 늘거나 같으면 된다).
- 평가 줄의 화면 낭독 이름은 기존처럼 문장으로 준다(`평균 별점 4.2점, 좋아요 12개` / `좋아요 3개, 평가 부족` / `아직 평가가 부족해요`). `★`·`👍` 기호가 기호 이름으로 읽히지 않게 한다.
- 모바일(360px)에서 2·3순위 두 장이 나란히 들어가야 한다.

## PM 판단으로 정한 것

- 반올림 값으로 등급 비교, 미확인 카드에 평균 숨김, 평가 줄 문구
- 평점을 쓸 수 없을 때 등급 없는 기본 카드
- 다이아 섬광 + 기존 폭죽 유지, 동작 줄이기 처리
- 낭독 안내에 등급 추가
- 기존 배지 요소 제거(카드 평가 줄로 대체)

## 구현자에게 맡기는 것

카드 크기·간격·글자 크기, 애니메이션 타이밍 세부(전체 길이는 지금과 비슷하게), 뒷면 디자인, 2·3순위 등장 효과, 다크 테마 색 조정, CSS 구조.
