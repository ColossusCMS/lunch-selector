# 1순위 공개 연출 — 설계·구현 계획 (사이클 019)

## 배경
- 지금 돌리기는 카드 뒷면에서 이름이 2초 돌다가 `?`에서 멈추고 앞면이 뒤집히는 정도라, 1순위가 정해지는 순간이 밋밋하다.
- 사용자가 코덱스 연출 실험(`D:\03.로컬작업장소\private-projects\gacha-reveal-lab\versions\01-roulette-dissolve.html`, 이하 **샘플**) 중 첫 번째 것을 골랐다. **룰렛이 돌고 결과가 나타나는 과정은 샘플 그대로** 쓴다.
- 연출은 결과를 모르는 상태에서 봐야 의미가 있으므로, 결과 화면에 "연출 보기" 버튼을 따로 두지 않고 **돌리기를 누르는 순간** 보여준다. 지금의 카드 자리(높이 240px)는 좁으므로 **화면 전체를 덮는 연출 창**으로 띄운다.

## 사용자 결정 (2026-11-05)
1. 위치: 돌리기를 누르면 화면 전체를 덮는 연출 창 → 끝나면 지금의 결과 화면.
2. 건너뛰기: 된다(화면을 누르면 넘어감).
3. 등급 차등: 둔다(샘플처럼).
4. 소리: **무음**. 샘플의 효과음 코드(`tone`·`chime`·`AudioContext`)는 가져오지 않는다. 추가 여부는 사용자가 나중에 결정.
5. 색: **어두운 화면만**. 앱 테마(시스템·라이트·다크)와 상관없이 연출 창은 샘플의 어두운 색. 라이트용은 사용자가 확인 후 필요하면 따로 요청.

## 동작

### 흐름
1. `🎰 돌리기`/`다시 돌리기` → 후보·1~3순위 계산(지금과 같음) → 연출 창이 열린다.
2. 연출 창은 **1순위만** 공개한다. 룰렛에 지나가는 이름은 이번 후보(`pool.list`) 이름들.
3. 연출이 끝나 1순위 카드가 공개되면 창은 그대로 머문다. 사용자가 화면을 누르거나 `결과 보기` 버튼·Esc로 닫는다.
4. 닫히면 지금 결과 화면을 보여준다. 단, **뒷면 이름 회전(`spinReel`)은 생략**하고 2·3순위 등장 → 1순위 카드 뒤집기 → 이후 동작(평가 기록 `last-pick`, 낭독, 지도 등)은 지금과 같다. 지도 주소 조회는 연출 중에 미리 시작한다(지금처럼).

### 등급별 차등 (샘플 기준, 1.0배속)
| 1순위 카드 등급 | 연출 |
|---|---|
| 원석 · 미확인(평가 2건 미만) · 평가 기능 꺼짐 | 샘플의 **원석 흐름**: 룰렛이 감속하며 가게 이름에서 멈추고 업종·이름을 짧게 보여준다 |
| 에메랄드 · 루비 · 다이아 | 샘플의 **긴 흐름**: 룰렛이 흐려지며 사라짐 → 빛 모임 → 업종 단서 → 등급 단서(등급별 시간·세기·문구) → 빛줄기·번쩍임 → 결과 카드 등장 |

- 등급은 지금 카드와 같은 `cardTier(...)` 값을 쓴다(연출과 카드의 등급이 달라 보이면 안 됨).
- 샘플의 등급 이름·색(에메랄드 `#75ecc0`, 루비 `#ff6e95`, 다이아 `#bcdeff`, 원석 `#c6baa5`)과 시간값을 그대로 쓴다. 속도는 샘플 기본값 **1.0배속**. 나중에 조정하기 쉽게 시간값은 한곳(상수)에 둔다.
- 결과 카드 내용: 등급 영문(예: `DIAMOND`), 가게 이름, 업종, `<등급> 카드`. 미확인·꺼짐은 원석 흐름이므로 등급 글자를 보이지 않는다(원석 흐름은 카드 없이 끝남 — 샘플과 같음).
- 업종 단서는 가게의 업종 값. 업종이 비어 있으면 그 단계를 건너뛴다.

### 건너뛰기
- 연출 중 화면(연출 창 어디든)을 누르거나 Esc → 진행 중인 효과를 멈추고 **바로 최종 공개 상태**로 간다(샘플의 `결과 바로 보기`와 같음).
- 최종 공개 상태에서 한 번 더 누르거나 `결과 보기`·Esc → 창이 닫히고 결과 화면.
- 두 번은 **따로따로의 터치**다(더블클릭 동작이 아님). 빠르게 두 번 눌러 공개 장면까지 한꺼번에 넘어가지 않도록, 최종 공개 상태가 된 뒤 약 0.5초 동안은 닫기 입력을 무시한다.
- 건너뛰기 버튼 추가·자동 닫기는 사용자가 이번 결과물을 보고 판단한다(이번 범위 아님).
- 화면 아래에 작은 안내 `화면을 누르면 건너뛰어요` → 최종 상태에서는 `결과 보기` 버튼으로 바뀐다.

### 움직임 줄이기
- `prefers-reduced-motion: reduce`이면 연출 창을 **열지 않는다**(지금의 calm 흐름 그대로 결과 바로 표시).

### 그 밖
- 샘플의 실험용 겉모습(머리말 `REVEAL LAB`, 오른쪽 조작판, 단계 표시 `01 룰렛…`, 시간 표시, `LIVE PREVIEW`·`TAKE` 글자)은 가져오지 않는다. 무대(룰렛 줄, 빛 모임, 단서 글자, 빛줄기, 번쩍임, 파문, 입자 캔버스, 결과 카드)만 가져온다.
- 연출 창은 `<dialog>` `showModal()`로 띄워 뒤쪽 조작을 막는다. 창이 열려 있는 동안 돌리기·칩 조작 불가(지금 `state.spinning`과 같음). 모드 전환 등으로 회차(`state.round`)가 바뀌는 경우는 없지만, 닫힌 뒤 회차가 바뀌었으면 결과 반영을 멈추는 지금 규칙을 유지한다.
- 화면 낭독기: 연출 중 이름 회전은 읽히지 않게(`aria-hidden`) 하고, 최종 결과 낭독은 지금처럼 결과 화면에서 한 번.
- 가게 이름은 `textContent`로만 넣는다(HTML 해석 금지). 긴 가게 이름은 카드 안에서 줄바꿈.
- 360px~데스크톱까지 창이 화면에 맞고 가로 스크롤이 생기지 않는다. 입자 캔버스는 창 크기를 따른다(기기 배율 최대 2).
- 연출이 끝나거나 닫히면 애니메이션 프레임·타이머를 남기지 않는다.

## 구현 기준 (코덱스 재량 범위)
- 새 모듈 `js/reveal.js`(연출 창 DOM·애니메이션)와 순수 로직 분리. 순수 로직 예: `revealPlan(tierId)` → `{ long: boolean, grade: {...} | null }`처럼 등급별 흐름·시간을 돌려주는 함수, `tests/reveal.test.js`로 테스트.
- 스타일은 `css/style.css`에 연출 창 구역으로 추가(어두운 색 고정, 앱 테마 변수에 영향받지 않게). 의존성 추가 금지, 외부 글꼴·요청 금지.
- `index.html`에 연출 창 `<dialog>` 추가. `js/app.js`의 `present()`에서 calm이 아닐 때 `spinReel` 대신 연출 창을 띄우고 닫힐 때까지 기다린다.
- `animation.js`의 `spinReel`이 더 쓰이지 않으면 지워도 된다(테스트·다른 사용처 확인).
- `APP_VERSION`은 바꾸지 않는다. `npm run bump`는 실행. README 기능 소개에 한 줄 + 테스트 수 갱신(이미지 재촬영 X).
- 화면 확인은 저장소 밖 복사본 + 가짜 CSV·가짜 평점 CSV(등급별 가게 준비).
- 계획과 다르게 해야 할 이유가 생기면 임의로 바꾸지 말고 보고에 질문으로 남기고 멈춘다.
