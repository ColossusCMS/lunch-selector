# 별점 선택 시각 강화 Implementation Plan (설계 포함)

> **For agentic workers:** 협업 규약에 따라 코덱스가 구현하고 `docs/agents/handoffs/007-rating-stars-visual.md`의 "구현 보고"를 채운다. **커밋하지 않는다.**

**Goal:** 평가 모달에서 몇 점을 골랐는지 한눈에 보이게 한다.

## 배경 (2026-11-03 사용자 피드백)

- 지금은 선택 별 `★`과 미선택 별 `☆`이 같은 주황색·같은 네모 버튼이라 속이 찼는지로만 구분된다. 작은 화면에서 눈에 잘 안 띈다.
- 사용자 채택: **A 색 대비 + B 점수 문구 + C 누를 때 효과**. (D "평가한 가게 줄 강조"는 채택 안 함)
- 모달 가로 폭·제목 줄바꿈 같은 세부 디자인은 **이번 범위 아님**. 다음 사이클에서 따로 잡는다. 이번에는 레이아웃을 크게 바꾸지 않는다.

## 결정

### A. 색 대비
- 선택된 별(1~N): 금색 `★`, 버튼 배경 연한 금색, 테두리도 금색 계열.
- 미선택 별: 회색 `☆`(배경·테두리는 기존 중립색). 주황(`--accent`)을 미선택 별에 쓰지 않는다.
- 라이트·다크 테마 모두에서 선택/미선택이 확실히 구분되고 글자 대비가 충분할 것. 색 값은 CSS 변수로 두고(테마별), 정확한 색은 구현자 재량.
- 상태는 기존 `choice.stars`에서 파생. 클래스(예: `.filled`)를 1~N번 별에 붙이는 방식 권장(지금 `aria-pressed`는 N번째 별에만 true인 기존 동작 유지).

### B. 점수 문구
- 문구: `1 별로예요`, `2 아쉬워요`, `3 괜찮아요`, `4 맛있어요`, `5 최고예요` → 화면에는 `별로예요`처럼 **말만** 표시(숫자 없음).
- 위치: 각 가게의 별 줄 **바로 아래 한 줄**. 별을 고르지 않았거나 해제했으면 비움. **줄 높이는 항상 확보**해서 문구가 나타나고 사라질 때 모달 높이가 흔들리지 않게 한다.
- 문구는 금색 계열 또는 강조색, 별보다 작은 글씨. `textContent`만.
- 순수 함수로 분리해 테스트: 예) `starLabel(n)` → `n`이 1~5면 문구, 그 외(`null` 등) `''`. 위치는 `js/rating.js`.

### C. 누를 때 효과
- 별을 누르면 **채워진 별들이** 짧게(약 0.2초) 커졌다 돌아온다(scale 1 → 1.2 → 1). 해제할 때는 효과 없음.
- 연속 클릭 시에도 매번 다시 재생되게(애니메이션 재시작 처리).
- `prefers-reduced-motion: reduce`에서는 효과 없음(기존 CSS의 reduce 블록 방식 따름).

## Global Constraints

- 변경 범위: `css/style.css`, `js/app.js`(평가 모달 별 렌더링 부분), `js/rating.js`(`starLabel`), `tests/rating.test.js`, 버전 bump로 바뀌는 `index.html`·`js/*.js`의 `?v=`. 그 밖의 파일·의존성 변경 금지. `js/config.js` 값 변경 금지.
- 평가 전송·기록 로직, 좋아요 버튼, 모달 크기·제목은 바꾸지 않는다.
- 실제 구글 폼 전송 금지. 화면 확인은 저장소 밖 복사본 + 가짜 설정(006 검증 스크립트 방식 재사용 가능).
- 작업 끝에 `npm run bump`.
