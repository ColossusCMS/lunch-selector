# 별점·좋아요 Implementation Plan

> **For agentic workers:** 협업 규약(`private-projects/shared/docs/agent-workflow.md`)에 따라 코덱스가 Task 순서대로 구현하고 인계 파일의 "구현 보고"를 채운다. **커밋하지 않는다.** Steps use checkbox (`- [ ]`) syntax.

**Goal:** 다음 접속 때 지난 추천 가게를 평가(별점·👍)하게 하고, 구글 폼 응답을 읽어 결과 카드에 평균 별점·좋아요 수 배지를 보여준다.

**Architecture:** 판정·집계·전송 본문 생성은 새 모듈 `js/rating.js`의 순수 함수로 두고 Node로 테스트한다. CSV 요청은 `js/data.js`의 공용 함수로 뽑아 가게 목록과 평점이 같은 제한 시간 경로를 쓴다. `js/app.js`는 저장·렌더·이벤트 연결만 맡는다.

**Tech Stack:** 순수 JS(ES Modules), Node 내장 test runner, 의존성 0

**Spec:** `docs/superpowers/specs/2026-11-03-rating-design.md` — 동작·문구·형식은 설계가 기준이다. 이 계획은 인터페이스와 테스트를 고정한다.

## Global Constraints

- 새 의존성·빌드 금지, `package.json` 수정 금지. 기존 64개 테스트 유지.
- 시트·응답 문자열은 `textContent`로만 출력(`innerHTML` 결합 금지).
- 평점 설정 값이 하나라도 비면 기능 전체 꺼짐: 카드·배지·저장·평점 요청 모두 없음. 현재 저장소 기본값은 **빈 값**으로 둔다(사용자가 폼을 만든 뒤 채움).
- 화면 문구(설계 그대로): `🍽️ {M/D} {모드명} 추천, 다녀온 곳이 있으면 평가해 주세요`, `보내기`, `안 갔어요`, `고마워요! 반영까지 몇 분 걸릴 수 있어요`, `보내지 못했어요. 다음에 다시 물어볼게요`.
- 폼 질문 제목: `모드`, `가게명`, `별점`, `좋아요`. 응답 CSV는 헤더 이름으로 읽는다.
- localStorage 키: `lunch-selector:last-pick`.
- 대기 30분, 보관 로컬 달력 3일.

## Review Focus

1. 평점 CSV가 느리거나 실패해도 가게 목록·돌리기가 막히지 않아야 한다 → Task 4 연결(별도 Promise, 실패 시 콘솔 경고만) + PM 화면 확인.
2. 평점 CSV의 헤더 순서가 다르거나 열이 더 있어도(폼 질문 추가·순서 변경) 집계돼야 한다 → Task 2 `aggregateRatings` 헤더 순서 테스트.
3. 저장된 `last-pick`이 깨진 JSON·옛 형식이면 앱이 죽지 않고 무시해야 한다 → Task 2 `parsePick` 테스트.
4. 기기 시계가 돌아가 `at`이 미래면 영원히 대기하지 않아야 한다 → Task 2 `pickStatus` 미래 시각 테스트(`drop`).
5. 카드가 뜬 뒤 새로 돌려 저장값이 바뀌면 카드 응답이 새 결과를 건드리지 않아야 한다 → Task 2 `applySendResults`/`dropIfSame` 의 `at` 불일치 테스트.

### Task 2: `js/rating.js` 순수 함수

**Files:** Create `js/rating.js`, `tests/rating.test.js`

**Interfaces (Produces):**
```js
/** @typedef {{ at: number, mode: string, names: string[] }} Pick */
/** @typedef {{ likes: number, avg: number | null }} RatingStat */

export const PICK_KEY = 'lunch-selector:last-pick';
export const MIN_WAIT_MS = 30 * 60 * 1000;
export const MAX_DAYS = 3;

export function ratingKey(mode: string, name: string): string          // 앞뒤 공백 제거 후 결합
export function aggregateRatings(rows: string[][]): Map<string, RatingStat>
export function formatBadge(stat: RatingStat | undefined): { text: string, label: string } | null
export function parsePick(raw: string | null): Pick | null
export function pickStatus(pick: Pick, now: number, modeIds: string[]): 'ask' | 'wait' | 'drop'
export function buildRatingBody(entries: { mode, name, stars, like }, rating: { mode: string, name: string, stars: number | null, like: boolean }): URLSearchParams
export function applySendResults(saved: Pick | null, cardAt: number, sent: string[], failed: string[]): Pick | null
export function dropIfSame(saved: Pick | null, cardAt: number): Pick | null
```

- [ ] **Step 1: 실패하는 테스트 작성** (`tests/rating.test.js`)

```js
test('aggregateRatings: 헤더 이름으로 읽고 모드+가게명으로 묶는다', () => {
  const rows = [
    ['타임스탬프', '가게명', '좋아요', '모드', '별점', '기타'],   // 순서 뒤섞임 + 여분 열
    ['t', '본죽', '1', 'lunch', '5', ''],
    ['t', ' 본죽 ', '', 'lunch', '4', ''],
    ['t', '본죽', '1', 'lunch', '', ''],
    ['t', '본죽', '1', 'cafe', '3', ''],
    ['t', '본죽', 'x', 'lunch', '9', ''],                          // 잘못된 값: 둘 다 무시
  ];
  const m = aggregateRatings(rows);
  assert.deepEqual(m.get(ratingKey('lunch', '본죽')), { likes: 2, avg: 4.5 });
  assert.deepEqual(m.get(ratingKey('cafe', '본죽')), { likes: 1, avg: 3 });
});
test('aggregateRatings: 빈 입력·필수 헤더 없음 → 빈 Map', () => {
  assert.equal(aggregateRatings([]).size, 0);
  assert.equal(aggregateRatings([['a', 'b'], ['1', '2']]).size, 0);
});
test('aggregateRatings: 평균은 소수 첫째 자리 반올림', () => {
  const rows = [['모드', '가게명', '별점', '좋아요'], ['l', 'A', '4', ''], ['l', 'A', '4', ''], ['l', 'A', '5', '']];
  assert.equal(aggregateRatings(rows).get(ratingKey('l', 'A')).avg, 4.3);
});
test('formatBadge', () => {
  assert.deepEqual(formatBadge({ likes: 12, avg: 4.2 }), { text: '★4.2 · 👍12', label: '평균 별점 4.2점, 좋아요 12개' });
  assert.deepEqual(formatBadge({ likes: 3, avg: null }), { text: '👍3', label: '좋아요 3개' });
  assert.deepEqual(formatBadge({ likes: 0, avg: 5 }), { text: '★5.0', label: '평균 별점 5.0점' });
  assert.equal(formatBadge({ likes: 0, avg: null }), null);
  assert.equal(formatBadge(undefined), null);
});
test('parsePick: 정상·깨진 값', () => {
  assert.deepEqual(parsePick('{"at":1,"mode":"lunch","names":["A"]}'), { at: 1, mode: 'lunch', names: ['A'] });
  for (const raw of [null, '', '{', '[]', '{"at":"x","mode":"l","names":["A"]}', '{"at":1,"mode":"l","names":[]}'])
    assert.equal(parsePick(raw), null, String(raw));
});
test('pickStatus: 30분 대기, 달력 3일, 모드 없음, 미래 시각', () => {
  const at = new Date(2026, 10, 6, 11, 50).getTime();          // 금 11:50 (로컬)
  const pick = { at, mode: 'lunch', names: ['A'] };
  const ids = ['lunch', 'cafe'];
  assert.equal(pickStatus(pick, at + 29 * 60e3, ids), 'wait');
  assert.equal(pickStatus(pick, at + 30 * 60e3, ids), 'ask');
  assert.equal(pickStatus(pick, new Date(2026, 10, 9, 23, 59).getTime(), ids), 'ask');   // 월(3일째)
  assert.equal(pickStatus(pick, new Date(2026, 10, 10, 0, 0).getTime(), ids), 'drop');  // 화(4일째)
  assert.equal(pickStatus({ ...pick, mode: 'gone' }, at + 60 * 60e3, ids), 'drop');
  assert.equal(pickStatus(pick, at - 24 * 60 * 60e3, ids), 'drop');                     // 시계가 하루 전으로
});
test('buildRatingBody', () => {
  const entries = { mode: 'entry.1', name: 'entry.2', stars: 'entry.3', like: 'entry.4' };
  const body = buildRatingBody(entries, { mode: 'lunch', name: '본죽', stars: 4, like: true });
  assert.equal(body.toString(), new URLSearchParams({ 'entry.1': 'lunch', 'entry.2': '본죽', 'entry.3': '4', 'entry.4': '1' }).toString());
  const empty = buildRatingBody(entries, { mode: 'lunch', name: '본죽', stars: null, like: false });
  assert.equal(empty.get('entry.3'), '');
  assert.equal(empty.get('entry.4'), '');
});
test('applySendResults: 실패한 가게만 남기고, 다 보내면 null, at 다르면 그대로', () => {
  const saved = { at: 5, mode: 'lunch', names: ['A', 'B', 'C'] };
  assert.deepEqual(applySendResults(saved, 5, ['A'], ['B']), { at: 5, mode: 'lunch', names: ['B'] });
  assert.equal(applySendResults(saved, 5, ['A', 'B'], []), null);
  assert.equal(applySendResults(saved, 4, ['A'], ['B']), saved);
  assert.equal(applySendResults(null, 5, ['A'], []), null);
});
test('dropIfSame', () => {
  const saved = { at: 5, mode: 'lunch', names: ['A'] };
  assert.equal(dropIfSame(saved, 5), null);
  assert.equal(dropIfSame(saved, 4), saved);
});
```

- [ ] **Step 2:** `npm test` → FAIL(모듈 없음)
- [ ] **Step 3:** 구현. 메모:
  - `aggregateRatings`: 첫 행이 헤더. `모드`·`가게명` 헤더가 없으면 빈 Map. 별점은 `/^[1-5]$/`(trim 후)만, 좋아요는 trim 후 `'1'`만.
  - `pickStatus` 판정 순서: 모드가 `modeIds`에 없음 → `drop`; 로컬 달력 날짜 차이(`now`의 로컬 자정 − `at`의 로컬 자정, 일 단위 반올림)가 0 미만이거나 `MAX_DAYS` 초과 → `drop`; `now - at < MIN_WAIT_MS` → `wait`; 그 외 `ask`.
  - `applySendResults`: `saved.at !== cardAt`면 `saved` 그대로. 아니면 `names`를 `failed`만 남김(카드에서 고르지 않은 가게도 빠짐). 비면 `null`.
- [ ] **Step 4:** `npm test` → 전부 PASS

### Task 4: 화면 연결

**Files:** Modify `js/app.js`, `index.html`, `css/style.css`

**Interfaces (Consumes):** Task 1 `fetchCsvRows`, Task 2 전부, Task 3 `RATING`·`ratingEnabled`.

`ratingEnabled(RATING)`가 false면 아래 전부 건너뛴다.

- [ ] **Step 1: 평점 읽기** — 앱 시작 시 한 번 `fetchCsvRows(RATING.csvUrl)` → `aggregateRatings` → `state.ratings`(Map). 가게 목록 로딩과 독립(기다리지 않음). 실패 시 `console.warn`만. 늦게 도착해도 이미 보이는 결과 카드를 다시 그릴 필요는 없다.
- [ ] **Step 2: 배지** — `fillRank`에서 `formatBadge(state.ratings?.get(ratingKey(state.mode.id, store.name)))`가 있으면 카드 오른쪽 위 배지 요소(`textContent`=text, `aria-label`=label). 1순위는 `.stage` 안 릴 박스 오른쪽 위 배지(릴 요소의 자식이 아니라 형제로, `spinReel`이 `textContent`를 덮어쓰지 않게). 릴이 멈춘 뒤 표시, `resetResult`에서 숨김.
- [ ] **Step 3: 마지막 추천 저장** — `present()`에서 결과가 확정되면 `storage.set(PICK_KEY, JSON.stringify({ at: Date.now(), mode: state.mode.id, names: picks.map(s => s.name) }))`.
- [ ] **Step 4: 평가 카드** — 시작 시 `parsePick(storage.get(PICK_KEY))` → `pickStatus(pick, Date.now(), modes().map(m => m.id))`. `drop`이면 키 삭제, `wait`이면 아무것도 안 함, `ask`면 카드 렌더(모드 버튼 위). 카드는 이때 읽은 `pick.at`을 기억한다.
  - 가게별 줄: 이름, 별 5개 버튼(같은 별 다시 누르면 해제), 👍 토글(`aria-pressed`). 별 버튼에는 `aria-label`(`별 N개`).
  - `보내기`: 고른 가게가 없거나 전송 중이면 비활성. 고른 가게마다 순서대로 `fetch(RATING.formUrl, { method: 'POST', mode: 'no-cors', body: buildRatingBody(RATING.entries, …) })`; reject면 실패 목록. 끝나면 `applySendResults(parsePick(storage.get(PICK_KEY)), cardAt, sent, failed)` 결과를 저장(null이면 키 삭제). 문구는 설계대로.
  - `안 갔어요`: `dropIfSame` 결과 저장/삭제 후 카드 숨김. `✕`: 카드만 숨김.
- [ ] **Step 5: 스타일** — 카드·별·배지를 기존 톤(강조색·칩)으로. 라이트/다크 모두 확인. 긴 가게명이 배지와 겹치지 않게.
- [ ] **Step 6:** `npm test` → 전부 PASS. 로컬 서버로 열어 설정이 빈 상태에서 기존 화면이 그대로인지 확인.
