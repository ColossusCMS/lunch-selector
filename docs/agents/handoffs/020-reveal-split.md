### 1. 룰렛은 카드 안에서 (모든 등급 공통)
- 019에서 덮는 창 안에 있던 **샘플의 룰렛**(세로로 흐르는 이름 줄, 가운데 강조·위아래 흐림, 감속)을 결과 화면 **1순위 카드 뒷면 안**(`#card-back`, 지금 `spinReel`이 돌던 자리)으로 옮긴다. 지나가는 이름은 이번 후보 이름들.
- 카드 뒷면은 앱 화면의 일부이므로 색은 **앱 테마(라이트·다크)를 따른다**(뒷면 지금 색 `--back-surface`·`--back-text` 기준). 카드 높이(240px)에 맞게 줄 높이·글자 크기는 조정해도 된다. 긴 가게 이름이 카드 밖으로 넘치면 안 된다.
- 룰렛이 도는 동안은 지금처럼 건너뛰기 없음(돌리기·칩 비활성).

### 2. 원석·미확인·평가 꺼짐 — 덮는 창 없음
- 카드 안 룰렛이 감속하며 **1순위 가게 이름에서 멈춘다**(샘플의 원석 흐름, 2900ms). 잠깐 보여 준 뒤(약 400ms, 상수) 지금처럼 2·3순위 등장 → 1순위 카드 뒤집기.
- 덮는 창은 열지 않는다.

### 3. 에메랄드·루비·다이아 — 룰렛이 사라지는 시점부터 덮는 창
- 카드 안 룰렛은 선택된 이름을 넣지 않고 돌다가(샘플의 긴 흐름, 2500ms), 마지막 750ms 동안 흐려지며 사라진다(샘플의 dissolve를 카드 안에서).
- **흐려지기 시작하는 순간 덮는 창이 열린다.** 창은 그 750ms 동안 서서히 나타나고(불투명도 0→1), 이어서 019의 빛 모임 → 업종 단서 → 등급 단서 → 빛줄기·번쩍임 → 결과 카드가 진행된다. 창 안에는 룰렛이 더 이상 없다.
- 창을 닫으면 019처럼 2·3순위 → 1순위 카드 뒤집기. 카드 뒷면에는 룰렛이 사라진 빈 상태가 보이지 않게 정리(예: 뒷면 기본 모양으로 되돌린 뒤 뒤집기).
- 전체 시간(창이 열리기 전 카드 안 1750ms 포함)은 019와 같게 유지.

### 4. 효과음 (샘플의 소리 그대로)
- 샘플의 Web Audio 합성음(`tone`·`chime`·`stopSound`)을 가져온다. 파일·외부 요청 없음. 별도 모듈(예: `js/sound.js`)로 분리.
  - 룰렛 틱(이름이 한 칸 지날 때마다, 긴 흐름은 사라지는 동안 작아짐) — 카드 안 룰렛에서
  - 원석 흐름 멈춤음(330Hz)
  - 빛 모임(75→210Hz), 업종 단서(410Hz), 등급 단서(100→360Hz, 등급 시간만큼), 결과 공개 화음(`chime`, 등급별 음)
- **켜고 끄는 버튼은 만들지 않는다. 기본 켜짐**(사용자가 이번 테스트에서 들어 보고 판단). 소리 크기는 샘플 값 그대로.
- 브라우저 자동 재생 제한 때문에 `AudioContext` 생성/`resume()`은 **돌리기 버튼 클릭 처리 안에서 동기적으로** 한다. 소리를 못 쓰는 환경(생성 실패 등)에서도 연출·결과는 정상.
