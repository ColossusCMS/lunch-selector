### 등급별 연출 시간 (1.0배속)

업종이 있는 경우, 창을 연 뒤 **최종 공개가 시작되는 시점**까지다. 창이 닫히는 시간은 사용자가 결정하므로 합산하지 않았다.

| 등급 | 상수 합계(ms) | Chrome 실측(ms) |
|---|---:|---:|
| 원석 | 2900 | 2910 |
| 미확인 | 2900 | 2901 |
| 평가 꺼짐 | 2900 | 3008 |
| 에메랄드 | 6730 | 6754 |
| 루비 | 7280 | 7313 |
| 다이아 | 7830 | 7844 |

- 원석은 공개 후 보조 문구 진입 500ms, 상위 등급은 결과 카드 진입 1050ms가 이어짐. 입자 잔광은 공개 후 최대 약3100ms 동안 자연 소멸. 최종 공개부터 500ms가 지나면 닫기 가능. 타이머/브라우저 프레임 스케줄링으로 실측에 수~100ms 차이가 있음.
- 업종이 없으면 상위 흐름에서 1600ms를 빼며, 다이아 실측6253ms(상수6230ms). 시간값은 `REVEAL_TIME` 및 등급별 duration에 모음.
