## 지시 (PM)

- 017~022가 아직 커밋 전이다. 그 위에 이어서 작업하고 되돌리지 않는다.
- 샘플 원본(읽기만): `D:\03.로컬작업장소\private-projects\gacha-reveal-lab\versions\01-roulette-dissolve.html`

### 동작 (사용자가 정한 것)
1. 결과가 다 나온 뒤(1순위 카드가 뒤집힌 뒤) **1순위 카드의 오른쪽 아래**에 `연출 다시보기` 버튼이 나타난다.
2. 버튼은 1순위 등급이 **에메랄드·루비·다이아일 때만** 나타난다. 원석·미확인·평가 꺼짐이면 없다. 2·3순위 카드에는 없다.
3. 누르면 **화면 전체를 덮는 창에서 룰렛부터 결과까지** 다시 보여 준다. 즉 019 처음 버전처럼 **창 안에서 샘플 룰렛이 돌고**(카드 안 룰렛이 아님) → 흐려지며 사라짐 → 빛 모임 → 업종 단서 → 등급 단서 → 빛줄기·번쩍임 → 결과 카드.

### 구현 기준 (PM 판단, 재량 범위)
- **창 안 룰렛:** 020에서 창 안 룰렛 DOM·스타일을 지웠으므로 샘플의 룰렛(세로 이름 줄, 가운데 강조·괄호, 위아래 흐림, 2500ms 감속, 마지막 750ms 흐려짐)을 창 안에 다시 넣는다. 019 때처럼 어두운 창 색. 룰렛 이름은 **그 회차 후보 전체**(022와 같이 1순위 포함, 시작 위치 무작위, 1순위에 멈추지 않음). 회차의 후보 이름·1순위·업종·등급은 결과를 낼 때 기억해 둔다(저장소에 저장하지 않음, 메모리만).
- **시간:** 창 안 룰렛 2500ms(흐려짐 1750~2500) 뒤 지금 상위 등급 흐름과 같은 순서·시간. 전체 시간은 019와 같음(에메랄드 6730, 루비 7280, 다이아 7830ms, 업종 없으면 단서 생략). 창 자체는 바로 나타난다(첫 공개 때의 750ms 서서히 나타나기는 다시보기에선 없어도 됨 — 룰렛이 창 안에 있으므로).
- **그대로 쓰는 것:** 건너뛰기(연출 중 터치·Esc → 최종 공개, 다시 터치 → 닫기, 0.5초 닫기 무시), 안내 문구, 5초 자동 닫기 + `자동으로 닫히기 N초 전`, 등급별 보석 그림, **효과음**(룰렛 틱 포함, 버튼 클릭 처리 안에서 `AudioContext` 활성화). 다시보기 중 룰렛 단계에서도 터치하면 최종 공개로 건너뛴다.
- **닫힌 뒤:** 결과 화면은 그대로다. 카드 다시 뒤집기·2·3순위 재등장·`last-pick` 재기록·낭독·지도 갱신을 **하지 않는다**. 포커스는 `연출 다시보기` 버튼으로 돌아온다.
- **여러 번:** 몇 번이든 다시 볼 수 있다. 매번 이전 회차 타이머·프레임·소리가 남지 않아야 한다.
- **버튼이 사라지는 때:** 새로 돌리기 시작·모드/지역/그룹/업종 변경 등으로 결과가 지워질 때(`resetResult`). 돌리는 중·연출 창이 열린 중에는 누를 수 없다.
- **움직임 줄이기:** 이 환경에선 첫 연출도 없으므로 **버튼을 보이지 않는다.**
- **버튼 모양:** 문구 `↻ 연출 다시보기`, 지금 `🙅 제외하기` 버튼과 같은 작은 버튼 계열(크기·모서리·글자)로, 카드 테두리 안쪽 오른쪽 아래에 둔다. 접근성 이름 `1순위 <가게명> 연출 다시보기`. 카드 장식(보석·반짝임)보다 위에 있어 눌려야 하고, 360px에서 가운데의 `제외하기`·카카오맵 링크·평가 줄과 **겹치면 안 된다**. 360px에서 같은 줄에 겹칠 수밖에 없다면 임의로 위치를 바꾸지 말고 보고에 캡처와 함께 질문으로 남기고 멈춘다.
- 순수 로직(버튼 표시 여부: 등급·움직임 줄이기 → boolean, 다시보기 계획 시간)은 `js/reveal-plan.js`에 두고 테스트.
- `APP_VERSION` 그대로, `npm run bump` 실행. README 기능 소개에 한 줄 + 테스트 수. 의존성 추가·커밋 금지. 화면 확인은 저장소 밖 복사본 + 가짜 CSV·평점.
